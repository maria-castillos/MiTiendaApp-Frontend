# 🛒 MiTiendaApp Frontend

Este es el **frontend de MiTiendaApp**, una aplicación web desarrollada con **HTML**, **CSS** y **JavaScript**.
“MiTiendaApp” es una aplicación móvil diseñada para digitalizar y facilitar las operaciones diarias de una tienda de barrio. 
Permitirá a los clientes visualizar productos disponibles, realizar pedidos a domicilio y recibir notificaciones sobre el estado de sus solicitudes. 
Por su parte, el tendero podrá registrar ventas, gestionar y actualizar el inventario en tiempo real, así como controlar y confirmar la entrega de productos.
---

## 🚀 Tecnologías utilizadas

* **HTML5** — Estructura de las páginas.
* **CSS3** — Diseño y estilos.
* **JavaScript (ES6)** — Lógica e interactividad.
* **Git / GitHub** — Control de versiones.

---

## ⚙️ Requisitos previos

* Un navegador moderno (Google Chrome, Edge, Firefox, etc.)

---

## 📦 Ejecución del proyecto

1. **Clonar el repositorio**

   ```bash
   git clone https://github.com/maria-castillos/MiTiendaApp-Frontend.git
   cd MiTiendaApp-Frontend
   ```

2. **Abrir el proyecto**

   * Si usas **VS Code**, ejecuta con la extensión **Live Server**.
   * O abre directamente `index.html` en tu navegador.
